# Between Things — October

Static, mobile-responsive events page for Between Things. Each event box links to its Google Form.

Icons: `favicon.ico`, `icons/` (favicons, app icons, `og-image.png` link preview, `social-square.png` profile picture) and `site.webmanifest`.

Deploy: import this repo on Vercel (Framework preset: "Other", no build command, output directory: root).
